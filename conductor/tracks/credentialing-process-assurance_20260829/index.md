# Credentialing privacy-minimised event and assurance pack

Status: in progress

This track adds a versioned credentialing ontology, privacy-minimised event
projection, conformance and metric boundary, and independent assurance agent.
The pack observes the process and produces human-reviewable evidence; it does
not manage cases or change workflows.
