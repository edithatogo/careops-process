# CI delivery scope

Adopt the five CareOps CI delivery requirements while preserving strict Python
quality, domain/property/privacy tests and optional-provider qualification.
Use reviewed immutable action SHAs and hash-locked dependencies. Keep one updater
per ecosystem and distinguish unavailable previews, setup/billing blocks and
executed test failures. Retain public-source boundaries and existing deployment
authority. Real packages require matching SBOMs and independently verified build
and SBOM attestations. Offline proofs do not establish native acceptance.
